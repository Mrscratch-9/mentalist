# @mentalist/desktop

Tauri 2 + React + Vite shell. Placeholder home only; no series data yet.

- `pnpm dev` / `pnpm tauri dev`: run the app
- `pnpm test`: progress store tests (Vitest)
- Fonts (Inter 300/400/500/600, Courier Prime) are bundled via @fontsource, no network.
- Progress lives in `src/state/progress.ts` (owner configured: season 6, episode 9).
